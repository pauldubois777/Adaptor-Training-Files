# Adaptor-Training-Files

This repo is so I can share training files for the Udemy course, "Apple Intelligence & Neural Networks Masterclass"

The video `32. 5.1-11 Adaptors` did not contain a resource for the training files, and the course's download did not contain the files.

I used Claude to generate the files you find here, and Claude use this prompt:
`I'll build both files: 400 training and 100 validation examples, each a different 80s movie or pop-culture question with an answer full of period slang, in the JSONL format Apple's adapter toolkit uses.`

Also from Claude:
- Two things to know:

  - These are my versions, not the instructor's originals, so the exact answers you see in the lecture won't match.
  - The slang is assembled from a set of openers and sign-offs, so phrases repeat across answers. That's fine for teaching the model the style, but if you'd like more varied wording I can rework them.
